# Family Upholstery — GitHub Pages version

This folder is ready to publish directly with GitHub Pages. No build command, Node.js installation, or GitHub Actions workflow is required.

## Publish

1. Replace the existing files in the `FamilyUpholsteryDraft` repository with everything inside this folder.
2. Confirm `index.html` is visible on the repository's main Code page—not inside another folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to finish and open the provided URL.

The `.nojekyll` file tells GitHub Pages to serve these files directly.
